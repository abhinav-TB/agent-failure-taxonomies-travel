# Scheme provenance and evidence boundary

The operational 13-class scheme is defined in the manuscript and used in analysis/mapping.md. The historical plan refers to a companion review. No supporting 24-taxonomy source list or crosswalk was supplied for verification. The revised manuscript therefore removes the claim that the scheme was synthesized from 24 publications. This file does not reconstruct or invent missing historical provenance. The historical plan is preserved unchanged and is an author-provided document, not a verified external registry record.

The current scheme is a common analyst-defined vocabulary, not a validated universal measurement instrument. Missing coding mechanisms are reported as UNMAPPABLE. TOOL_FORMAT boundaries remain disputed; see strict sensitivity and the 27-row audit. Further source-provenance materials can be added only if supplied and verified.
